# FoodBridge Frontend

The React 19 + TypeScript + Vite frontend client for FoodBridge.

## Features
- Multi-role dashboards (Donor, NGO, Admin)
- Interactive Leaflet map with routing
- AI Food Rescue Assistant powered by Groq
- 5-language localization
- Dark and light theme toggle

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. (Optional) Configure environment:
   ```bash
   cp .env.example .env
   ```

3. Start development server:
   ```bash
   npm run dev
   ```

The application runs on `http://localhost:3000`.
